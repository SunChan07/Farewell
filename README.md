# Farewell: Salatnica Language Model

Проект кастомной 16-слойной GPT-подобной языковой модели с уникальной встроенной механикой динамического прореживания весов (Dynamic Sparsity - DST), эволюционным отбором нейронов и мутациями синапсов (`HPConfig`).

Вес скомпилированной модели составляет **1.14 ГБ**, архитектура полностью оптимизирована для локального инференса и ускоренного обучения с использованием тензорных ядер в режиме смешанной точности **AMP (FP16)**.

---

## 🎨 Архитектурные особенности

* **Биологическая эволюция весов (HPLinear):** Кастомные линейные слои оценивают собственную градиентную эффективность на каждой эпохе. Слабые, неиспользуемые нейроны «болеют» (теряют HP) и отправляются на полную перезагрузку (`reborn`), а на их месте вырастают новые связи, мутировавшие под воздействием регулируемого случайного шума.
* **Динамическая разреженность (DST):** В процессе базового обучения сеть автоматически прореживает синапсы от базовой плотности `1.0` до целевых `0.60` (задается параметром `sparsity=0.4`), оставляя только самые мощные сквозные магистрали связей.
* **Современный GeGLU Декодер:** Использование функции активации `GELU` в механизме вентиляции (Gated Feed-Forward) защищает градиенты от затухания, свойственного стандартным ReLU-архитектурам.
* **Двойная защита от переобучения:** Label Smoothing (`0.15`) совместно с высоким коэффициентом затухания весов Weight Decay (`0.08`) обеспечивают высокую ментальную гибкость и препятствуют банальному зазубриванию датасета.

---

## ⚙️ Технические характеристики

* **Количество слоев:** 16 слоев декодера
* **Размерность эмбеддинга (`embedding_dim`):** 768
* **Головы внимания (`num_heads`):** 12
* **Длина контекста (`SRC_LEN / TGT_LEN`):** 128 токенов
* **Размер словаря (`vocabulary`):** до 16 000 уникальных слов
* **Базовый формат весов:** PyTorch FP32 (с поддержкой инференса и AMP FP16 обучения)

## 🛠️ Рычаги управления и параметры (`HPConfig`)

Вы можете тонко настраивать характер, креативность и жесткость логики бота прямо через конфигурацию тренера:
* `sparsity` — целевой уровень прореживания связей.
* `mutation_rate` — частота возникновения случайных изменений в «застоявшихся» слоях. Помогает модели выходить из локальных минимумов.
* `max_damage` — сила штрафа и снижения HP неэффективных нейронов при высоком показателе Loss.
* `temperature` и `repetition_penalty` — оперативное управление выходом токенов (уровень фантазии бота и подавление цикличных повторов).

## 🚀 Быстрый старт

### Требования
Для локального запуска рекомендуется видеокарта с поддержкой CUDA и объемом памяти от **8 ГБ** (например, RTX 2080 Super и новее), а также установленная библиотека **PyTorch**.

### Установка и клонирование
```bash
git clone https://github.com/SunChan07/Farewell.git
cd Farewell
```

### Запуск обучения и чата
Убедитесь, что ваш файл датасета `mixed_dialogues.txt` находится в корневой папке проекта.
```bash
python FarewellAI.py
```

Проект автоматически подхватит вашу CUDA-видеокарту, проведет инспекцию тензорных ядер (AMP FP16) и запустит 50 базовых эпох обучения с использованием оптимизатора SGD, косинусного расписания (`warmup_epochs=3`) и финального усреднения весов SWA. После этого когнитивный модуль перейдет в интерактивный режим диалога.
